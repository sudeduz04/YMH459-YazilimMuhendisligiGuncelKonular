# YMH459-YazilimMuhendisligiGuncelKonular

**YMH459 Yazılım Mühendisliğinde Güncel Konular · Vize Çalışması**  
**Hazırlayan:** Sude Düz

Bu çalışmada, 20 litrelik çelik varillerde sıcak tutkalı eritip üretim hattına besleyen **VERMAK IGM 20 DRUM** incelenmiştir. Laboratuvar föyleri, makine emniyeti ile endüstriyel siber güvenliğin kesiştiği durumları ele alır. SWOT analizi ise makinenin özelliklerini, sınırlamalarını ve kullanıldığı tesisin koşullarını değerlendirir.
